# HAHA.dll — Roblox Parry Script

**Educational purposes only.** Do not use to cheat on protected games or violate Terms of Service.

## What It Does

- Auto-detects incoming balls and fires parry requests
- Real-time accuracy scaling based on ping
- Manual spam, triggerbot, and performance metrics
- Roblox RemoteEvent hooking for educational study

## Features

- **Auto Parry**: Automatic ball detection and parry firing
- **Manual Spam**: Rate-limited manual firing (avoid lag)
- **Triggerbot**: Fire on ball target changes
- **Accuracy Slider**: 40–100%, with auto ping-scaling
- **Live Metrics**: Ball velocity, ping, effective accuracy

## Setup

1. Paste into executor console
2. UI appears on screen
3. Toggle and adjust sliders as needed
4. Drag title bar to move

## How It Works

Hooks the parry RemoteEvent, tracks ball positions, predicts hit window based on speed/distance/ping, sends crafted requests.
